# Linux Programming — Summative Project

This repository contains five independent projects for the Linux Programming summative assessment. Each project lives in its own subfolder with a dedicated README covering compilation, execution, inputs, expected outputs, and design notes.

All projects target a **Linux environment** (native Linux, WSL, or a VM).

## Projects

| # | Folder | Description |
|---|--------|-------------|
| 1 | [`Project_1_Investigating_an_ELF_Executable/`](Project_1_Investigating_an_ELF_Executable/) | C program and ELF binary analysis using `readelf`, `objdump`, `strace`, and `gdb` |
| 2 | [`Project_2_Assembly-Based_Text_File Analysis/`](Project_2_Assembly-Based_Text_File%20Analysis/) | x86-64 assembly program that counts total and valid lines in a sensor readings file |
| 3 | [`Project_3_Python_C_Extension/`](Project_3_Python_C_Extension/) | Python C extension module for high-performance sensor data statistics |
| 4 | [`Project_4_Designing_a_Multithreaded_Order_Processing_System_in_C/`](Project_4_Designing_a_Multithreaded_Order_Processing_System_in_C/) | Multithreaded producer–consumer food delivery simulation using `pthread` |
| 5 | [`Project_5_Building_a_Concurrent_TCP_Client–Server_Monitoring_System/`](Project_5_Building_a_Concurrent_TCP_Client–Server_Monitoring_System/) | Concurrent TCP client–server system for lab equipment reservation |

Open the README inside each folder for build and run instructions.
